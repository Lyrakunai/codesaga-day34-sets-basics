## 🧠 What I Learnt
- Set stores only unique values
- Duplicate values are automatically ignored
- Set does not support indexing
- Set is unordered, so output order can change
- Empty set is created using set()
- add() is used to add values in set
- remove() is used to delete values from set
- append() is not used in set
- Membership checking is done using in
- Set works using a hash-based system
